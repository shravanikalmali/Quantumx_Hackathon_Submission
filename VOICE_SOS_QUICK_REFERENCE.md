# Voice SOS - Quick Reference Guide 🎤

## What's New?

✅ **Voice Recording** - Speak your emergency
✅ **AI Analysis** - Automatic incident classification
✅ **User Confirmation** - Review before dispatch
✅ **Responder Options** - Choose from nearby responders
✅ **No Auto-Dispatch** - You always have final say

---

## How to Use

### Step 1: Open SOS
```
Tap red "SOS" button (top right of home screen)
```

### Step 2: Choose Input Mode
```
Voice  → Speak your emergency
Text   → Type your emergency
```

### Step 3: Voice Mode (New!)
```
1. Tap microphone button
2. Speak clearly: "Large fire near warehouse"
3. Tap Stop when done
4. Confirm transcription (can edit)
5. System analyzes...
```

### Step 4: Review Analysis
```
You see:
- Incident Type: FIRE
- Severity: 85%
- Urgency: CRITICAL
- Resources: fire_truck, ambulance, rescue_team

Options:
✅ Confirm & Dispatch
❌ Reject (try again)
```

### Step 5: Choose Responder
```
System shows nearby responders:
- Fire Station (2.3 km)
- Ambulance (1.8 km)
- Police (3.1 km)

You can:
🗺️ View on Map
📞 Call Responder
```

## Voice Recording Features

### Recording Indicator
- **Pulsing microphone** - Shows recording is active
- **"Recording..."** text - Confirms recording started
- **"Speak now"** hint - Prompts user to speak

### Transcription
- **Auto-prompt** - Shows what system heard
- **Editable** - You can fix mistakes
- **Confirm** - Tap to send to AI

### Example
```
You say: "Medical emergency, person unconscious"
System hears: "Medical emergency person unconscious"
You can edit: "Medical emergency - person unconscious at home"
Tap Analyze: Sends to AI
```

## Tips & Tricks

### For Best Voice Recognition
- Speak clearly and slowly
- Avoid background noise
- Describe what you see
- Include location details

### Example Good Descriptions
```
✅ "Large fire near warehouse on 27th Main, HSR Layout"
✅ "Person unconscious at home, not responding"
✅ "Car accident on Bangalore-Mysore highway, 2 vehicles"
✅ "Flooding in basement, water rising fast"
```

### Example Bad Descriptions
```
❌ "Fire" (too vague)
❌ "Something bad happened" (unclear)
❌ "Help" (no details)
❌ "I don't know" (not helpful)
```

### If AI Gets It Wrong
- Tap "Reject"
- Try again with more details
- Or switch to "Text" mode
- Edit and resubmit

## Troubleshooting

### Issue: Microphone Not Working
**Solution**:
1. Check microphone permission in Settings
2. Try Text mode instead
3. Restart app

### Issue: Transcription Incorrect
**Solution**:
1. Edit the transcription text
2. Add more details
3. Tap "Analyze" again

### Issue: AI Analysis Wrong
**Solution**:
1. Tap "Reject"
2. Try again with clearer description
3. Include location & details

### Issue: Can't Find Responders
**Solution**:
1. Check internet connection
2. Verify location is enabled
3. Try expanding search radius
4. Call 112 directly
